# To-Do-App

<h2>To-Do-App</h2><br>
<p>A simple and efficient to-do list application that helps users manage their daily tasks.
This project was created to practice building CRUD functionality and clean UI/UX.</p><br>

<h2>Features</h2><br>
<p>1.Add new tasks</p>
<p>2.Mark tasks as completed</p>
<p>3.Delete tasks</p>


<h2>Technologies Used</h2><br>
<p>Frontend: HTML, CSS, JavaScript</p>
